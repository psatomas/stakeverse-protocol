# StakeVerse Protocol

A simplified Web3 staking and governance protocol built with Solidity and Hardhat.

## Features

- ERC-20 governance token
- ERC-721 participation NFT
- Staking rewards system
- Simplified DAO governance
- Chainlink oracle integration
- Sepolia testnet deployment

## Tech Stack

- Solidity
- Hardhat
- OpenZeppelin
- ethers.js
- React
- Chainlink
